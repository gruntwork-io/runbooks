Runbooks can be opened by launching the desktop app or via the command line.

See the [opening a runbook reference](/commands/open/) for the full list of flags and supported URL formats.

## Opening a Runbook

There are two ways to open a runbook:

1. **Double-click** a `.mdx` file in Finder (macOS file association opens it in the Runbooks desktop app).
2. **Use the command line** to open a runbook from a local path or remote URL:

```bash
# Local
runbooks open ./runbooks/deploy-rds

# Remote (GitHub URL copied from the browser)
runbooks open https://github.com/org/repo/tree/main/runbooks/deploy-rds

# Remote (git source in go-getter syntax, as in a Terragrunt source)
runbooks open github.com/org/repo//runbooks/deploy-rds?ref=v1.0
```

For remote sources, Runbooks clones the repository that holds the runbook and opens the runbook in the desktop app. The whole repository is cloned, so a runbook can use files outside its own directory. You can also paste any of these sources into **Open from URL** in the desktop app.
