Runbooks is a desktop app. Launch it from its app icon or with the `runbooks` command, which takes a local path or a remote URL as the runbook source.

- [`runbooks open`](/commands/open/) opens a runbook in the desktop app.
- [Watch mode](/commands/watch/) reloads a runbook while you author it.
- [Sessions](/commands/sessions/) covers what Runbooks saves for each runbook and how it resumes.

## Launching from the command line

```bash
runbooks open ./path/to/runbook
```

Run `runbooks` with no arguments to resume the [session](/commands/sessions/#resuming-a-session) you last launched from the current directory.

## Remote URLs

You can open a runbook from a remote URL without downloading its files first.

```bash
runbooks open https://github.com/org/repo/tree/main/runbooks/launch-rds
```

See [`runbooks open`](/commands/open/#remote-sources) for supported URL formats and authentication for private repos.
