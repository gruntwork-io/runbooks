## Author in your editor

A runbook is a `runbook.mdx` file. Keep it in git next to the infrastructure it documents and review it in pull requests.

<CardGrid>
  <Card title="MDX authoring" icon="pen">
    Markdown plus [blocks](/authoring/blocks/) such as `<Check>`, `<Command>` and `<Template>`.
  </Card>
  <Card title="Lives in git" icon="github">
    Open a runbook from a local folder or straight from a GitHub or GitLab URL.
  </Card>
  <Card title="Watch mode" icon="approve-check">
    `runbooks open --watch` reloads the runbook in the app each time you save it. [Learn more →](/commands/watch/)
  </Card>
</CardGrid>

## Generate files and open pull requests

The `<Template>` block renders files from a [Gruntwork Boilerplate](/authoring/boilerplate/) template using the values a developer enters, previews them in a file tree, and writes them to disk.

Combine `<GitClone>`, `<Template>` and `<GitHubPullRequest>` to clone a repo, generate files into it, and open a pull request.

<CardGrid>
  <Card title="Boilerplate templates" icon="add-document">
    Generate files and folders from a template. Variables come from form inputs. [Learn more →](/authoring/blocks/template/)
  </Card>
  <Card title="Inline templates" icon="document">
    Define small templates directly in your runbook MDX and give users inline previews. [Learn more →](/authoring/blocks/templateinline/)
  </Card>
  <Card title="Clone and PR" icon="github">
    Clone a repo with `<GitClone>`, make changes, and open a pull request with `<GitHubPullRequest>`. [Learn more →](/authoring/blocks/gitclone/)
  </Card>
  <Card title="File preview" icon="open-book">
    Generated files appear in a file tree with syntax highlighting, so developers can read them before committing.
  </Card>
</CardGrid>

## Open source desktop app

Gruntwork Runbooks is a desktop app for macOS, Linux and Windows. There is no server to deploy.

<CardGrid>
  <Card title="Desktop app" icon="laptop">
    Download an installer from the [GitHub releases page](https://github.com/gruntwork-io/runbooks/releases).
  </Card>
  <Card title="Local execution" icon="setting">
    Commands and scripts run on the developer's machine, with the developer's own credentials.
