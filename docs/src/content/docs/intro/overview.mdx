Gruntwork Runbooks is a desktop app that opens runbooks. A runbook is a markdown document with interactive blocks that collect input, generate files, and run scripts.

Runbooks is [open source](https://github.com/gruntwork-io/runbooks), built by [Gruntwork](https://gruntwork.io), and free to use.

## What can Runbooks do?

Runbooks loads a runbook file and:

- Renders its markdown text
- Collects user input in forms it generates from the runbook
- Uses the values the user entered to:
  - Generate files and folders from templates
  - Run scripts
  - Run checks

## How is Runbooks useful?

Platform and DevOps engineers often know how to do an infrastructure task that application engineers need done. A runbook lets the platform engineer write that task down once, so the application engineer can complete it without waiting for help.

Runbooks is useful for:

- developer self-service
- setting up landing zones
- documenting internal processes or standard operating procedures
- codifying all the ways to use a given IaC pattern

Learn more by reading about [Runbooks use cases](/intro/use_cases/).

## How is a runbook structured?

A typical runbook directory looks like the file tree below. The file names are arbitrary, but the folder names are conventional.

<FileTree>

- runbook.mdx
- assets/
  - architecture.jpg
- checks/
  - preflight_checks.sh
- scripts/
  - install_mise.sh
- templates/
  - consume_lambda_module/
    - boilerplate.yml
    - terragrunt.hcl

</FileTree>

A `runbook.mdx` file contains markdown and interactive [blocks](/authoring/blocks/). Blocks can reference files in the `assets/`, `checks/`, `scripts/`, and `templates/` directories. See [Authoring Runbooks](/authoring/overview/) for the details.

## How do you open a runbook?

Runbooks open in the Runbooks desktop app. From the app, choose **Open Runbook** or **Open from URL** on the welcome screen. From a terminal, pass `runbooks open` a local path:

```bash
runbooks open /path/to/runbook
```

Or pass it a remote URL, without cloning the repo first:

```bash
runbooks open https://github.com/org/repo/tree/main/runbooks/launch-rds
```

Runbooks supports GitHub and GitLab browser URLs, as well as OpenTofu-style source addresses. See [`runbooks open`](/commands/open/) for all supported formats and for authentication with private repos.
