The scripts don't need to be executable. Runbooks reads each one and runs it with the interpreter its first line names.

## Open your runbook

Save the files and open the runbook:

```bash
runbooks open my-first-runbook/
```

If your terminal can't find `runbooks`, [install the command](/intro/installation/#installing-the-runbooks-command), or choose **Open Runbook** on the app's welcome screen and pick the folder.

The Runbooks window opens and shows the runbook. Work through it from top to bottom and run each block.
